# DeCura Mobile App

DeCura (branded Skintelligence) is a skincare and haircare tracking app for the European Union market, built with React Native, Expo and Supabase.

## Repository layout

| Path | Contents |
|---|---|
| `CLAUDE.md` | Working rules for the primary coding agent and the advisory council |
| `.claude/agents/` | The six advisory council agents |
| `docs/release/` | Release definitions (requirements baselines) |
| `docs/governance/` | Data Protection Impact Assessment, validation, master data and data quality documents |
| `docs/reviews/` | Recorded council reviews |

Start with `docs/release/release-1-definition.md`.

## Security note

This repository is public. Never commit secrets, access keys, environment files or any real user data.
